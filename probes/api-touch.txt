# 探针触达的具名接口清单（供 scripts/coverage.sh 计算覆盖率）
#
# 格式：包|符号|用例
#   - 符号必须能在该包的 pkg.generated.mbti 里找到 `pub fn <符号>(`
#   - 用例必须是 probes 包实际存在的 case 名
# 两条都由脚本校验，写错任何一条脚本都会失败退出——清单不能被"顺手多写"。
#
# 不登记运算符（* / % + - << >> 等）：它们由 `pub impl` 提供，调用点写作运算符，
# 源码里没有符号名，无法静态判定触达，因此分子分母都不含运算符重载。
# 这是少算，不是多算：真正被测的行为比这张表多。
#
# builtin 是隐式导入的类型（String / Double / Char / BytesView），
# 其接口在 $CORE/builtin/pkg.generated.mbti。
